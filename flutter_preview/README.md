# Prévia Flutter Bloomy

Este laboratório importa components_bloomy diretamente. Consulte o README na raiz.
`lib/main.dart` compõe telas com dados sintéticos; `lib/preview_bridge*` comunica somente o identificador da tela ao ambiente pai. Não há tokens de API no código Flutter.

Após editar, execute `npm run build:native` na raiz e atualize a prévia. Para desenvolvimento Flutter isolado, exporte GITEA_PUB_TOKEN do .env da raiz e use as ferramentas Flutter habituais. O alvo validado nesta entrega é web em 402 × 874.
